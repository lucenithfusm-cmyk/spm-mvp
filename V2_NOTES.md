# SPM MVP 2.0 — Review Notes

This branch contains the first V2 implementation for review before replacing the live V1.

## What changed

- Professional responsive redesign.
- 19-question English/Spanish assessment.
- Six-domain scoring and two-domain prioritization.
- Safety gating for age, possible priapism, exertional red flags, and significant genital pain/injury.
- Personalized 28-day wellness plan.
- Daily check-ins and progress metrics.
- Local browser persistence.
- Commercial offer placeholder at US$39.
- Removed duplicate uppercase `Index.html`.

- Privacy policy, terms and consent flow.
